# M. Hruthika — Developer Portfolio

A responsive personal developer portfolio built with HTML5, CSS3, and vanilla JavaScript for the Datheon Full Stack Web Development Internship, Task 1.

## Features

- Responsive, mobile-first layout
- Dark theme by default and light/dark theme toggle
- Mobile navigation menu
- Smooth section navigation
- Project cards with accessible detail dialogs
- Theme preference saved in `localStorage`
- Scroll reveal effects with reduced-motion support
- Semantic HTML and basic accessibility attributes

## Tech stack

- HTML5
- CSS3 (Grid, Flexbox, media queries)
- JavaScript (ES6+)
- Google Fonts

## Run locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
4. Edit the content and test it on desktop and mobile screen sizes.

No build command or backend server is required.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository named `Datheon-Developer-Portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages section.

## Deploy with Vercel

1. Push this folder to a GitHub repository.
2. Sign in to Vercel and import the repository.
3. Choose **Other** as the framework preset if asked.
4. Leave the build command and output directory empty; this is a static HTML site.
5. Deploy and open the generated URL.
